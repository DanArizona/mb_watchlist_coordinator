## What is new

The separately sealed multi-40-v1 profile permits 40 broker-confirmed Hot symbols
and up to 40 additions outside opening r1. An authorization requires the existing
Nasdaq reason, exact catalog/broker identity, admission and membership checks.
There is no synthetic/fallback roster in the live entry. The identity service
reserves each call durably, spaces starts by at least two seconds and never
repeats a saved unknown outcome. Limits are 120 identity calls in total and three
per symbol; 40 is a ceiling, not a promise of that many successful admissions.

Collection keeps the same schema-v2 daily journal, cadence, quote batch size and
0.75-second dispatch limit. Active five-minute periods bound acquisition-payload
verification work. All membership history and every value in the active period
are checked. Closed periods retain their original ledgers and verified stored-value
receipts. A current heartbeat does not claim to have rechecked old closed payloads.
After stop, the independent reporter compares all Hot values with those receipts;
an unfinished period is read against its original native response/ACK ledger,
without API, recovery writes or authentication. Native coverage audit, Hot value
integrity and event-order equality are reported separately. Native CLI full replay
remains available for projection/export.

New identity-approved requests can wait roughly ten seconds plus the normal pump/publication delay for a membership batch. The interval is retained from acknowledged publication outcomes across resume; pending native publication ACK recovery and membership reductions bypass batching.

Publication/request caches reuse only derived parsing after complete current-value
comparisons; timestamps, file size or a final hash alone are never trust shortcuts.
An inner publication collision yields without replaying a provider operation.
A genuine second source owner remains blocked. Native idle checks are aligned to
upcoming quote slots and bounded below the unchanged three-second progress gate.
This reduces idle CPU work while preserving every scheduled quote and live fence.
